## 📌 Project Overview
This repository contains the technical deliverables and executive briefing materials for the Week 8 Capstone: **Quarterly Operations Review**. 

Building upon the predictive maintenance and machinery health monitoring developed in Weeks 6 and 7, this project transitions from reactive fixed-interval distribution to a dynamic, condition-based supply chain framework for the Kenya Pipeline Company (KPC). By integrating time-series forecasting with linear optimization, the model guarantees a 95% service level across regional depots while minimizing emergency logistics costs and throughput stoppages.
